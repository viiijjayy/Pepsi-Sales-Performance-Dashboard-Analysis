# PepsiCo Sales & Distribution Performance Dashboard

### Turning Retail Fieldwork Data into Business Insights with Power BI

## 📌 Project Overview

This project focuses on analyzing fieldwork-based sales and distribution data collected during my PepsiCo marketing internship. The objective was to transform retail outlet observations and estimated sales data into an interactive Power BI dashboard that helps explore sales performance, regional trends, product movement, and outlet-level patterns.

By combining practical fieldwork exposure with data analytics, this project demonstrates how business data can be transformed into meaningful visual insights to support sales monitoring and distribution-related decision-making.

## 🎯 Business Objectives

- Analyze estimated sales performance across different outlet types and regions.
- Examine daily sales value and estimated unit movement.
- Compare product variants based on estimated sales.
- Identify outlets with higher estimated sales and product movement.
- Evaluate weekly sales against the target configured for the dashboard.
- Present key findings in an interactive, business-oriented report.

## 📊 Dashboard Highlights

The dashboard includes the following components:

### 1. KPI Overview
- Daily Total Sales
- Units Sold per Day
- Average Sales per Outlet
- Total Outlets Covered

### 2. Sales Performance Analysis
- Daily sales by outlet name
- Daily sales by region
- Daily sales by outlet type

### 3. Product & Distribution Analysis
- Estimated sales by product variant
- Daily sales associated with marketing materials (POSM)
- Outlets with the highest movement of selected SKUs

### 4. Target Monitoring
- Weekly sales performance against the configured target

### 5. Interactive Business Insights
- Outlet type and regional comparisons
- Product-level sales patterns
- Relationship between daily sales value and unit movement
- Interactive slicers for outlet type, outlet name, region, and POSM

## 💡 Key Findings

Based on the current dashboard view:

- **Channel concentration:** Supermarkets account for approximately 92.34% of the displayed daily sales.
- **Regional performance:** Vyttila records the highest displayed regional sales, at approximately ₹0.85M.
- **Product performance:** Pepsi leads the displayed product variants, with approximately ₹5M in estimated daily sales.
- **Target tracking:** Displayed weekly sales are approximately ₹100.44M against a configured target of ₹100M.

These observations describe the current dataset and dashboard calculations. They should not be interpreted as official company-wide PepsiCo performance figures.
